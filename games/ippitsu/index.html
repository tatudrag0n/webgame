一筆の旅Ippitsu no Tabi — One-Stroke Puzzle

すべての辺を、一筆で（辺を二度通らずに）なぞってゴール。点をタップして順に進もう。辺の奇数個持ちの点はスタートかゴールになる。

面 1
進捗 0 / 0
経過 0.0s
ベスト —

一筆達成！

スタート点を選んでください。
ルール・操作
1. 点をタップ・クリックして順に進むと、通った辺が消えていく。すべての辺を消せばクリア。
2. 使った辺は二度通れない。行き止まりになったら「一手戻す」でやり直せる。
3. 辺の本数が奇数の点（光る点）は、スタートかゴールにしかできない。
4. 「新しい手配」でいつでも別の問題が生成される。ベストタイムはこのブラウザに保存される。
