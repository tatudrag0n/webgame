ひかりのみち灯の径

光源から出た光を鏡で折り、すべての的を同じ色の光で灯す。色ガラスを通ると光の色が変わる。

灯りました

つくり

  • 鏡：クリック（タップ）で / と \ が入れ替わる。光は直角に折れる。
  • 分光器：光を2つに分ける。まっすぐ抜ける光と、鏡のように折れる光。折れる向きも入れ替えられる。
  • 色ガラス：通った光をその色に変える。色は 紅・翠・瑠璃 の3つ。
  • 的：同じ色の光を吸って灯る。ちがう色の光は素通りする。同じ色の的が並んでいる場合、手前の的が光を吸ってしまうので、分光器で分けよう。
  • 壁：光を止める。
操作：マスをクリック／タップで回転（なぞると連続で回せる）。←↑↓→ で移動、Space で回転、U で戻す、R でやり直す。 クリア状況と最少手数はこのブラウザに保存されます。
