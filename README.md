# webgame

ブラウザだけで遊べるウェブゲームです。インストールは不要です。

## ゲーム

| ゲーム | 遊び方 |
| --- | --- |
| [創発の庭](games/emergent-garden/) | セル・オートマトンのルールを操り、増殖する感染体からコアを守る創発サバイバル。壁を描き、誕生・生存条件を変えて生き延びろ。 |
| [タイムエコー](games/time-echo/) | 自分の動きを録画して過去の自分 (ゴースト) を生成し、協力してスイッチを踏み扉を開けて出口へ行くタイムループパズル。 |

## 遊び方

1. このリポジトリの [index.html](index.html) を開く
2. または GitHub Pages を有効にする

### GitHub Pages

1. リポジトリの **Settings** → **Pages**
2. Branch を `main`、フォルダを `/ (root)` にする
3. 保存すると、数分後に `https://tatudrag0n.github.io/webgame/` で遊べる

ゲームは1つの HTML ファイルなので、ファイルを直接ブラウザで開いても遊べます。
