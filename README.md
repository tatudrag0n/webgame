# webgame

ブラウザだけで遊べる、かんたんなウェブゲーム集です。インストールは不要です。

## ゲーム

| ゲーム | 遊び方 |
| --- | --- |
| [弓のタワーディフェンス](games/bow-defense/) | 画面下の大きなクロスボウに、自分で矢を装填して弦を引く。上から降るスライムを城の前で止めよう。 |
| [失われたエコーのアーカイブ](games/archive-of-lost-echoes/) | 届きかけた残響を「聴いて収める」か「送り返す」か選びながら、アーカイブを育てる。深く聴くほど次の残響は届きにくくなる。 |
| [ルール当て](games/guess-the-rule/) | 隠されたルールを yes / no のヒントから推理する。言葉を試して、わかったらルール名を入力して答える。 |
| [灯の径](games/light-path/) | 光源の光を鏡と分光器で折り、色ガラスで色を変えながら、すべての的を同じ色の光で灯す光路パズル。マスをクリック／タップで回転（なぞると連続で回せる）。矢印キーで回せるマスを選び、Space で回転、U で戻す、R でやり直す。ヒントと「答えを見る」（その径の最少手数で自動的に解く）つき。全10の径で、クリア状況と最少手数はブラウザに保存される。 |
| [陰陽リバーシ](games/reversi/) | はさんだ相手の石を返す 8×8 のリバーシ。相手は陰陽師（コンピュータ）で、難易度は やさしい／ふつう／つよい の3段階。先手（陰）と後手（陽）を選べる。置ける場所の表示、待った（相手の手も1手戻す）、ヒントつき。勝敗の記録はこのブラウザに保存される。 |
| [星影の絵解き](games/nonogram/) | 行と列の数字を頼りにマスを塗るピクロス。数字は「左（上）から順に、塗りのかたまりの長さ」。5×5・10×10・15×15 が12枚ずつで、どの絵も左右対称・答えはひとつ・線の論理だけで解ける。クリック／ドラッグで塗り、右クリック／長押しで印、モードボタンで塗る・印・消すを切り替え。ヒントは「論理だけで決まるマス」を教えてくれる。誤り表示・時間・大きさごとの最速タイムつき。 |
| [伏せられた祠](games/minesweeper/) | 数字を頼りに祟りを避けて祠を開くマインスイーパ。最初の一撃は必ず安全（設定で切り替え可）。右クリック／長押しで札、数字をクリックすると周囲をまとめて開く。難所は 9×9・祟り10／16×16・祟り40／30×16・祟り99 の3つで、難所ごとの最速タイムはこのブラウザに保存される。 |
| [百鬼夜行サバイバー](games/hyakki-survivor/) | 見下ろし型の生存アクション。WASD / 矢印キーで動き、攻撃は自動。スペース（または右半分タップ）で無敵の「祓い」ダッシュ。魂を集めると「浄化の儀」が始まり、呪符・結界・式神・雷符・狐火と加護から呪力を選んで育てる。最初の大妖怪は約1分半で現れ、以後は約2分おきに強くなってやってくる。Esc / P で一時停止、記録はこのブラウザに保存される。 |

## 遊び方

1. このリポジトリの [index.html](index.html) を開く
2. または GitHub Pages を有効にする

### GitHub Pages

1. リポジトリの **Settings** → **Pages**
2. Branch を `main`、フォルダを `/ (root)` にする
3. 保存すると、数分後に `https://tatudrag0n.github.io/webgame/` で遊べる

各ゲームは1つの HTML ファイルなので、ファイルを直接ブラウザで開いても遊べます。
