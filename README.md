# webgame

ブラウザだけで遊べる、かんたんなウェブゲーム集です。インストールは不要です。

## ゲーム

| ゲーム | 遊び方 |
| --- | --- |
| [スネーク](games/snake/) | 矢印キー、または画面のボタンでヘビを動かす。エサを食べると長くなる。自分や壁に当たると終了。 |
| [神経衰弱](games/memory/) | カードをめくって、同じ絵を2枚そろえる。 |
| [2048](games/2048/) | 矢印キー、またはスワイプでタイルを動かす。同じ数字がくっつくと合計になる。2048 を目指す。 |
| [まるばつ](games/tic-tac-toe/) | コンピュータと三目並べ。自分は ○。 |

## 遊び方

1. このリポジトリの [index.html](index.html) を開く
2. または GitHub Pages を有効にする

### GitHub Pages

1. リポジトリの **Settings** → **Pages**
2. Branch を `main`、フォルダを `/ (root)` にする
3. 保存すると、数分後に `https://tatudrag0n.github.io/webgame/` で遊べる

各ゲームは1つの HTML ファイルなので、ファイルを直接ブラウザで開いても遊べます。
